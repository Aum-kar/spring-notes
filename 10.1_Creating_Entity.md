# Creating Entity

## Class/Table Level Annotation

| Annotation          | Description                                              | Important Parameters                                                                                                                                             | Package                                |
| ------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| `@Entity`           | Marks class as a JPA entity (mapped to a database table) | `name` → optional entity name (JPQL name)                                                                                                                        | `jakarta.persistence.Entity`           |
| `@Table`            | Configures table mapping details                         | `name` → table name<br>`schema` → schema name<br>`catalog` → catalog name<br>`uniqueConstraints` → array of `@UniqueConstraint`<br>`indexes` → array of `@Index` | `jakarta.persistence.Table`            |
| `@UniqueConstraint` | Defines table-level unique constraint                    | `name` → constraint name<br>`columnNames` → columns included                                                                                                     | `jakarta.persistence.UniqueConstraint` |
| `@Index`            | Defines database index                                   | `name` → index name<br>`columnList` → columns                                                                                                                    | `jakarta.persistence.Index`            |

## Primary Key & ID Generation

| Annotation           | Description                             | Important Parameters                                                                                            | Package                                 |
| -------------------- | --------------------------------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| `@Id`                | Marks field as primary key              | —                                                                                                               | `jakarta.persistence.Id`                |
| `@GeneratedValue`    | Defines ID generation strategy          | `strategy` → `AUTO`, `IDENTITY`, `SEQUENCE`, `TABLE`<br>`generator` → generator name                            | `jakarta.persistence.GeneratedValue`    |
| `@SequenceGenerator` | Configures sequence-based ID generation | `name` → generator name<br>`sequenceName` → DB sequence<br>`allocationSize` → allocation size<br>`initialValue` | `jakarta.persistence.SequenceGenerator` |
| `@TableGenerator`    | Configures table-based ID generation    | `name`<br>`table`<br>`pkColumnName`<br>`valueColumnName`<br>`allocationSize`                                    | `jakarta.persistence.TableGenerator`    |

## Column-Level Annotations

| Annotation    | Description                                                             | Important Parameters                                                                                                                                                                              | Package                          |
| ------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| `@Column`     | Configures column mapping                                               | `name` → column name<br>`nullable` → true/false<br>`unique` → true/false<br>`length` → varchar length<br>`updatable` → true/false<br>`insertable` → true/false<br>`columnDefinition` → custom SQL | `jakarta.persistence.Column`     |
| `@Lob`        | Marks field as large object (CLOB/BLOB)                                 | —                                                                                                                                                                                                 | `jakarta.persistence.Lob`        |
| `@Enumerated` | Defines how enum is stored                                              | `value` → `EnumType.STRING` or `EnumType.ORDINAL`                                                                                                                                                 | `jakarta.persistence.Enumerated` |
| `@Temporal`   | Defines temporal type for `java.util.Date` (not needed for `java.time`) | `value` → `DATE`, `TIME`, `TIMESTAMP`                                                                                                                                                             | `jakarta.persistence.Temporal`   |
| `@Transient`  | Field is not persisted                                                  | —                                                                                                                                                                                                 | `jakarta.persistence.Transient`  |
| `@Version`    | Enables optimistic locking                                              | —                                                                                                                                                                                                 | `jakarta.persistence.Version`    |

## Relationship Annotations

| Annotation    | Description               | Important Parameters                                  | Package                          |
| ------------- | ------------------------- | ----------------------------------------------------- | -------------------------------- |
| `@OneToOne`   | One-to-one relationship   | `mappedBy`<br>`cascade`<br>`fetch`<br>`optional`      | `jakarta.persistence.OneToOne`   |
| `@OneToMany`  | One-to-many relationship  | `mappedBy`<br>`cascade`<br>`fetch`<br>`orphanRemoval` | `jakarta.persistence.OneToMany`  |
| `@ManyToOne`  | Many-to-one relationship  | `optional`<br>`cascade`<br>`fetch`                    | `jakarta.persistence.ManyToOne`  |
| `@ManyToMany` | Many-to-many relationship | `mappedBy`<br>`cascade`<br>`fetch`                    | `jakarta.persistence.ManyToMany` |

## Join /Foreign Key Configuration

| Annotation     | Description                                | Important Parameters                                                                                  | Package                           |
| -------------- | ------------------------------------------ | ----------------------------------------------------------------------------------------------------- | --------------------------------- |
| `@JoinColumn`  | Configures foreign key column              | `name` → FK column<br>`nullable`<br>`unique`<br>`updatable`<br>`insertable`<br>`referencedColumnName` | `jakarta.persistence.JoinColumn`  |
| `@JoinColumns` | Multiple join columns                      | `value` → array of `@JoinColumn`                                                                      | `jakarta.persistence.JoinColumns` |
| `@JoinTable`   | Configures join table (many-to-many)       | `name`<br>`joinColumns`<br>`inverseJoinColumns`                                                       | `jakarta.persistence.JoinTable`   |
| `@MapsId`      | Maps relationship to part of composite key | `value` → attribute name                                                                              | `jakarta.persistence.MapsId`      |

## Hibernate-Specific (Not Pure JPA)

| Annotation           | Description                                      | Important Parameters | Package                                       |
| -------------------- | ------------------------------------------------ | -------------------- | --------------------------------------------- |
| `@CreationTimestamp` | Automatically sets creation time                 | —                    | `org.hibernate.annotations.CreationTimestamp` |
| `@UpdateTimestamp`   | Automatically updates timestamp on entity update | —                    | `org.hibernate.annotations.UpdateTimestamp`   |
| `@DynamicInsert`     | Generates INSERT with only non-null fields       | —                    | `org.hibernate.annotations.DynamicInsert`     |
| `@DynamicUpdate`     | Generates UPDATE with changed fields only        | —                    | `org.hibernate.annotations.DynamicUpdate`     |
