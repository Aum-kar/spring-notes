# Entity Lifecycle States in JPA/Hibernate

There are mainly 4 core states of Entity lifecycle

1. Transient
2. Managed
3. Detached
4. Remove

## Transient (new/untracked)

- This is a plain Java object.
- It is not associated with the persistence context.
Hibernate does not know about it.

Example:

```java
Product product = new Product();
product.setName("Mouse");
```

At this point:

- No row in database.
- Not tracked.
- No SQL will be generated.

It becomes managed only after:

```java
productRepository.save(product);
```

## Managed (Persistent)

This is the most important state.
An entity is managed when:

- It is fetched using repository (e.g., findById)
- Or it is saved inside a transaction

Example:

```java
Product product = productRepository.findById(1L).get();
```

Inside a `@Transactional` method, this entity is managed. Meaning:

- Hibernate tracks changes to it.
- Dirty checking is active.
- No need to call save() after modifying it.

If you do:

```java
product.setPrice(new BigDecimal("1000"));
```

Hibernate will detect the change and generate UPDATE during flush.

## Detached

An entity becomes detached when:

- The transaction ends.
- The persistence context is closed.
- Or the entity is manually detached.

Example:

```java
Product product;

@Transactional
public void method() {
    product = productRepository.findById(1L).get();
}
// transaction ends here
```

After method finishes:

- product is detached.
- Hibernate is no longer tracking it.
- Changes will NOT be saved automatically.

If you now do:

```java
product.setPrice(new BigDecimal("500"));
```

No SQL will run. To persist changes, you must reattach:

```java
productRepository.save(product);
```

## Removed

This state happens when you call:

```java
productRepository.delete(product);
```

Inside transaction:

- Entity is marked for deletion.
- DELETE SQL runs during flush.
- After commit, row is removed from database.

## Comparison

| State     | Tracked by Hibernate? | Exists in DB?      | Auto Dirty Checking? |
| --------- | --------------------- | ------------------ | -------------------- |
| Transient | No                    | No                 | No                   |
| Managed   | Yes                   | Yes                | Yes                  |
| Detached  | No                    | Yes                | No                   |
| Removed   | Yes (until commit)    | Yes (until commit) | Not applicable       |
